# aprender/: para quem está aprendendo

Nada nesta pasta é usado pelo código do produto. Se você apagar a pasta, o Raio-X continua funcionando.
Ela existe para o time (e quem chegar depois) entender o projeto e saber o que rodar.

Leia nesta ordem:

| arquivo | para quê | tempo |
|---|---|---|
| [claude-code.md](claude-code.md) | como começar e terminar uma sessão do Claude Code (`/inicio-de-sessao`, `/fim-de-sessao`), os modos e os limites | 10 min |
| [COMANDOS.md](COMANDOS.md) | o que rodar, em qual pasta, e o que deve aparecer na tela | consulta |
| [entenda-o-projeto.md](entenda-o-projeto.md) | o projeto explicado para iniciantes: os conceitos e o caminho dos dados | 20 min |
| [passo_a_passo.ipynb](passo_a_passo.ipynb) | segue **uma empresa** do começo ao fim e confere cada passo. Antes de cada célula, você prevê o resultado | 40 min |
| [seguindo-o-projeto.md](seguindo-o-projeto.md) | foto de 26/10: como diagnosticar um projeto, com o comando que prova cada item. O que falta **hoje** está no [REQUISITOS](../docs/REQUISITOS.md) | consulta |
| [atalhos/](atalhos/) | dois cliques no Mac: configurar a chave, rodar os testes, abrir a tela | — |

O que o professor exige está nos arquivos dele, em [../docs/professor/](../docs/professor/) (eles valem mais que qualquer nota);
o status de cada requisito, em [../docs/REQUISITOS.md](../docs/REQUISITOS.md); o plano com datas e donos, em [../docs/PLANO.md](../docs/PLANO.md).

**Como entender um código que você não escreveu:**
1. Rode o código antes de ler.
2. Siga um exemplo concreto (uma empresa), não o arquivo de cima para baixo.
3. Preveja o resultado antes de rodar cada passo.
4. Se errou a previsão, pergunte "por quê?" à IA, pedindo explicação para iniciante sem alterar nada.
5. Explique em voz alta para outra pessoa. Se não consegue explicar, ainda não entendeu.
