# Requisitos para o desenvolvimento do projeto

* Equipe de 4 pessoas
* Deve ser entregue via repositório no GitHub ou GitLab

## Composição do projeto

   Itens que devem ser entregues.

1. ### Documentação

   - Em markdown, criar um read-me sobre o tema, objetivo, e as tecnologias utilizadas para o desenvolvimento. Além das instruções para executar o projeto;
   
   - Criar slides para apresentação (apresentação será no máximo 20 minutos);

   - Criar um documento, podendo ser em markown ou pdf, explicando as etapas desenvolvidas durante o processo;

   - Criar o BPMN do processo da regra de negócio da aplicação.

2. ### Machine Learning ou integração com IA de terceiros

   O projeto deve contemplar uma das abrodagem da área de IA:

   - Treinamento de Machine Learning: Adquirir uma base de dados, pública ou pode aquisitar dados, realizar a limpeza, análise e transformações dos dados, treinar uma ML para resolver um determinado problema e utilizar na aplicação.

   - Integração com IA de terceiro: Integrar com uma API de IA para resolver um problema. Deve ser utilizado uma base de dados de conhecimento para a IA utilizar, e caso se aplicar, realizar o processo de análise, limpeza e transformação dos dados.

3. ### Aplicação

   Podendo ser uma aplicação WEB ou Mobile (ou ambos), o sistema deve conter os seguintes itens:

   - Backend e Frontend, podendo utilizar qualquer framework que desejar.

   - Banco de dados à sua escolha.

   - Infraestrutura automatizada com Terraform, podendo rodar localmente ou na nuvem.

   - Arquivos utilizados de prompts para o vibecoding.
